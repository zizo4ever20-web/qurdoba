# تَحَدِّي الْجُمَلِ الْقِرَائِيَّةِ — مدارس قرطبة

تطبيق ويب تعليمي تفاعلي مخصص لطلاب الصفوف الأولية (٦ - ٩ سنوات)، يهدف لتنمية مهارة القراءة والتركيب النحوي الصحيح (فعل + فاعل + مفعول به / جار ومجرور).

- **المؤسسة التعليمية:** مدارس قرطبة الأهلية
- **تصميم وإعداد:** أ. أحمد الشربيني — مشرف الصفوف الأولية

---

## مميزات التطبيق

1. **بنك متكامل يحتوي على ١٠٠ جملة مصنفة:**
   - ١-١٠: الأفعال اليومية
   - ١١-٢٠: البيت والأسرة
   - ٢١-٣٠: الحيوانات
   - ٣١-٤٠: الطبيعة
   - ٤١-٥٠: المدرسة والتعلم
   - ٥١-٦٠: الطعام والشراب
   - ٦١-٧٠: الصحة والسلامة
   - ٧١-٨٠: المواصلات والأماكن
   - ٨١-٩٠: أفعال متنوعة
   - ٩١-١٠٠: السلوك والقيم

2. **التصميم البصري والتربوي:**
   - مؤشرات لونية نحوية:
     - **الفعل:** أحمر (`#bd080b`)
     - **الفاعل:** أزرق (`#075694`)
     - **المفعول به / الجار والمجرور:** ذهبي (`#df7200`)
   - خط **Noto Naskh Arabic** الواضح والمشكول بالكامل.
   - أزرار لمس كبيرة تناسب شاشات الأجهزة اللوحية والجوال والسبورات الذكية.

3. **أنماط اللعب:**
   - **وضع التحدي ⏱️:** مؤقت ٩٠ ثانية مع احتساب النقاط (+١٠ للصحيح، -٢ للخطأ).
   - **وضع التعلم 🌟:** تدرّب مفتوح بدون وقت مع إمكانية التنقل بين الجمل.

4. **مؤثرات صوتية ونطق آلي:**
   - مؤثرات صوتية تفاعلية مشيدة بالكامل عبر **Web Audio API** بدون الحاجة لأي ملفات صوتية خارجية.
   - نطق عربي فوري للجملة عند اكتمالها عبر **Web Speech Synthesis API**.

5. **تكريم وشهادة تفوق:**
   - إمكانية طباعة شهادة تفوق رسمية للطالب بصيغة A4 معتمدة من مشرف الصفوف الأولية أ. أحمد الشربيني.
   - حفظ تلقائي لأعلى الدرجات في الذاكرة المحلية `localStorage`.

6. **تصدير كملف مستقل (Single-file Offline):**
   - زر مباشر لتحميل ملف `qurtuba-reading-challenge.html` المستقل الذي يعمل بدون إنترنت على أي جهاز.

---

## تعليمات النشر (Deployment Guide)

### أ) النشر عبر GitHub Pages:
1. ارفع المشروع إلى مستودع GitHub.
2. اذهب إلى **Settings > Pages**.
3. اختر مسار النشر من فرع `main` أو أنشئ بناء Vite عبر GitHub Actions (`npm run build`).

### ب) النشر عبر Netlify أو Cloudflare Pages:
1. اربط المستودع.
2. إعدادات البناء:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`

### ج) التشغيل بدون إنترنت (Offline):
اضغط على زر **"حفظ ملف مستقل"** في شريط رأس التطبيق، وسيتم تنزيل صفحة HTML متكاملة تحتوي على الأكواد والخطوط والـ١٠٠ جملة لتعمل في أي فصل دراسي دون حاجة لاتصال بالإنترنت.
